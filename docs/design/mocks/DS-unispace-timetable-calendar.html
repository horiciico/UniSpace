4 · A week that mixes types (the rule)

If any day of the week is in an exam session, the whole week uses the hourly grid (one grid per week). The banner names the session. Holiday days in that week show "Holiday" and have no booking links. The server checks every booking by the date it is for, so the grid is only a guide.
